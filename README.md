# 🐦‍🔥 dsh-like-zcode

> **DeepSeek Harness 插件:致敬 2026-09-18「ZCode 静默备份事件」的镜像版。**
> 同样全量、同样静默、连 .git 历史都备——但服务器是你自己填的,开关默认关,私钥在你手里,带宽你限速。

2026 年 9 月 18 日,开发者发现智谱 ZCode 在后台静默打包并上传本地工程全量代码
(含完整 Git 历史):**42,411 个文件、313MB 加密包、564 次上传、解密私钥仅存云端**,
起因是默认开启的 "Repo Wiki" 索引功能,且关闭界面隐私开关无效。

本插件复刻那次事件的「形」,拒绝复刻它的「里子」:

| | ZCode 事件 | dsh-like-zcode |
|---|---|---|
| 开关 | 默认开启,关不掉 | **默认关闭**,必须亲手打开 |
| 去向 | 厂商云 | **你自己填的服务器**(云厂商 / NAS / 本地盘) |
| 私钥 | 仅存云端 | 仅存**本地**(可选端到端加密) |
| 感知 | 前端无任何通知 | 自动备份同样静默(梗本体),但进度随时在插件设置页可见 |
| 带宽 | 564 次上传 | 令牌桶限速 + 并发上限 + 夜间窗口 + 延迟自适应降速 |
| 开源 | 事后补票 | 第一行就是开源的 |

**它不窃取任何代码**:目标必须是用户亲手填写的、持有凭据的存储;总开关默认关;
每一步(目录、服务器、限速、加密、保留策略)都是用户显式配置。每个环节,自主可控。

## 特性

- **全量代码库备份**:含 `.git` 版本历史(可选),尊重 `.gitignore`,默认排除 node_modules 等
- **内容寻址去重**:第二次备份只有真正变化的文件走网络(通常接近 0 字节),
  却保留每一时点的完整快照——比 ZCode 的 313MB 整包重传优雅得多
- **快照清单**:任意时刻的可还原点,保留策略自动清理超份数旧清单
- **静默运行**:自动备份不产生任何会话消息/弹窗/提示(结构上就不注入会话 UI);
  进度实时显示在 设置 → 插件 → Like ZCode 卡片
- **带宽自律**:全局令牌桶限速(默认 4MB/s)、并发上限、夜间窗口、RTT 升高自动降速
- **可选端到端加密**:AES-256-GCM + scrypt,私钥只在你本机(反着致敬"私钥仅存云端")
- **零第三方运行时依赖**:S3 SigV4 签名、WebDAV 客户端、加密全部用 Node 内建模块实现
- **多后端**:
  - `localdir` —— 本地盘 / 移动硬盘 / U 盘 / **Windows 映射盘(= SMB 直连 NAS)**
  - `webdav` —— 群晖、威联通、坚果云、Nextcloud、Alist 等;**只有一台 ECS?**
    随插件附带单文件 Python 服务端 `server/like-zdav.py`,两条命令起步(见
    [docs/BACKENDS.md](docs/BACKENDS.md))
  - `s3` —— 阿里云 OSS、腾讯云 COS、七牛 Kodo、华为 OBS、Cloudflare R2、
    Backblaze B2、MinIO、AWS S3 等一切 S3 兼容端点

## 安装

```bash
# 在 dsh 的 profile 中安装(以 web profile 为例)
dsh plugin --profile web add @y1x1n/dsh-like-zcode
# 或从本地源码
dsh plugin --profile web add E:\path\to\dsh-like-zcode
```

重启 dsh web profile 后,打开 **设置 → 插件 → Like ZCode**。

## 快速上手

1. **填目录**:「备份内容」里每行一个要备份的绝对路径(如 `E:\work\project-a`)
2. **填服务器**:「备份目标」选类型并填地址/凭据(各厂商参数见 [docs/BACKENDS.md](docs/BACKENDS.md)),
   点 **测试连接** 确认可用
3. **定规矩**:限速、计划(手动/按间隔/夜间窗口)、是否加密、保留多少份快照
4. **打开总开关**(默认是关的——这是本插件与它致敬对象的第一个区别)
5. 手动触发:`/backup now`;或设置页点 **立即备份**

命令:

```
/backup            # 立即静默备份(后台执行,一句话确认,不刷屏)
/backup status     # 查看进度与最近快照
/backup pause      # 暂停
/backup resume     # 继续
/backup cancel     # 取消(已上传的去重进度保留,续传近乎免费)
```

## 远端目录结构

```
<remotePrefix>/                 默认 dsh-like-zcode,可改
├── meta.json                   插件标记("用户本人主动开启并知情")
├── keymeta.json                加密元数据:仅 salt + 校验令牌,不含密钥
├── blobs/<前2位>/<sha256>      内容寻址存储块(gzip[+加密])
└── snapshots/<时间戳>.json.gz  快照清单(含文件列表/哈希/大小/计数)
```

## 关于「静默」的边界(把话说清楚)

- **自动备份**(interval/window 模式触发):不写会话、不发通知、不弹窗、
  不打印控制台。日志只落 `~/.dsh/like-zcode/logs/`。这是对梗本体的忠实复刻。
- **手动动作**(`/backup`、设置页按钮):你亲手按的,给一句确认。你自己的操作应当有回声。
- **可见性**:设置 → 插件 → Like ZCode,1.5s 轮询实时进度(阶段/进度条/速度/ETA/当前文件/快照历史)。
- **总闸**:不配置服务器、不打开开关,它一个字节都不会动。

## FAQ

**Q:它会偷偷上传我的代码吗?**
A:不会。它没有除了你配置的后端之外的任何网络行为——代码里没有别的 URL,
没有遥测,没有更新检查。这也是它和本体的根本区别:本体后来连"修复后仍检测到上传"。

**Q:会影响我正常上网吗?**
A:全局令牌桶限速(默认 4096 KB/s)+ 并发上限 2 + 夜间窗口模式 + 对后端 RTT
探测自动降速(延迟升高降到 50%/25%)。四个旋钮都在设置页。

**Q:加密后还能去重吗?**
A:能。IV 由密钥与内容哈希收敛推导(收敛加密),同内容同密文,去重不受影响;
代价是"内容是否相同"这一信息对服务器可见——这是内容寻址的固有属性,是否接受由你决定。

**Q:忘记加密口令怎么办?**
A:数据还在,但永远解不开了。我们实在学不会"私钥存云端"的先进经验。

**Q:为什么是 `known-*.json` 本地索引?**
A:免掉每次备份对每个文件 HEAD 探测的风暴。删掉它也不影响正确性,只会慢一次。
